# AI logs

This folder is for the full transcripts of the AI agent sessions used to build the project.

**There are no transcripts here yet.** They are added only after the author has reviewed them (for secrets, personal paths and anything else that shouldn't be shared), so an empty folder means the review hasn't happened, not that nothing was logged.

What is available now:

- [`PROMPTS.md`](../PROMPTS.md): every prompt sent to the agent, in order.
- [The map (#1)](https://github.com/Khalifa1997/KNIME_Task/issues/1) and its tickets: the decisions and the reasoning behind them.

The agent was the Pi coding agent, with Claude models. See "How AI was used" in the [root README](../README.md).
